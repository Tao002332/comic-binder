# Comic Binder 可视化客户端工具 — 完整开发提示词

## 项目概述

Comic Binder 是一个基于 Python + PySide6 的桌面 GUI 应用，用于将漫画压缩包和 Kindle 下载的漫画文件批量转换为 PDF/EPUB 等格式。支持自动识别漫画系列名、将同一漫画的不同卷/话归入文件夹、多线程并行处理、进度追踪。

---

## 技术栈

| 类别 | 技术 |
|------|------|
| 语言 | Python 3.10+ |
| GUI 框架 | PySide6 (Qt for Python) |
| 压缩包处理 | `zipfile`(内置)、`rarfile`、`py7zr`、`patool` |
| PDF 生成 | `img2pdf` (无损，保持图片质量) |
| 图片处理 | `Pillow` |
| Kindle 转换 | Calibre 的 `ebook-convert` 和 `ebook-meta` CLI 工具 |
| 自然排序 | `natsort` |
| 配置持久化 | `QSettings` |
| 多线程 | `QThread` (严禁使用 `ThreadPoolExecutor`) |

## 详细功能说明

### 一、全局设计

**UI 风格**：iOS 毛玻璃卡片风格
- 整体背景 `#f2f2f7`
- 卡片 `rgba(255,255,255,0.72)` 半透明白，`0.5px` 细边框，`16px` 连续圆角
- 主色调 `#007aff` iOS 蓝
- 字体优先 SF Pro Display → 微软雅黑 → PingFang SC
- 系统级折叠面板：头部 50px，左侧粗体标题 + 右侧 `›`/`⌄` 箭头按钮（QPushButton，28×28px，hover 变色）

**复选框**：所有位置统一使用显式 `_CB_STYLE` 样式（不依赖全局 stylesheet）：
```python
_CB_STYLE = """
    QCheckBox::indicator { width: 22px; height: 22px; border: 2px solid rgba(0,0,0,0.22); border-radius: 5px; background-color: rgba(255,255,255,0.90); }
    QCheckBox::indicator:checked { background-color: #007aff; border-color: #007aff; }
"""
```

**路径持久化**：所有输入/输出/Calibre 路径通过 `QSettings("ComicBinder", "ComicBinder")` 自动保存和恢复。

### 二、Tab1：压缩包转 PDF（`archive_tab.py`）

**Step 1 — 文件夹设置**
- 两个毛玻璃卡片：输入文件夹 + 输出文件夹
- 每张卡片：灰色小标签 + QLineEdit + "浏览" 按钮
- "扫描压缩包" 蓝色主按钮
- 路径恢复：`get_last_path("archive/input_dir")` / `get_last_path("archive/output_dir")`

**Step 2 — 文件列表**
- 按漫画名自动分组折叠（使用 `extract_comic_name` 提取漫画名）
- 每个漫画组 = 一个 `_GlassPanel`：
  - 头部：组复选框 + 漫画名（粗体）+ 文件统计 + `›` 折叠箭头
  - 展开：QTableWidget，列 0=复选框(42px固定)，列 1..N=数据列(stretch)
  - 行高 42px，交替行色，0.5px 分割线
- 顶部工具栏：搜索框 + 展开全部/折叠全部/全选/取消全选/删除选中
- 底部：删除源文件复选框 + 返回 + 开始转换按钮
- 表格单元格可选中复制（`ItemIsSelectable | ItemIsEnabled`）
- 搜索过滤匹配漫画名及所有字段值

**Step 3 — 进度面板**
- 顶部：总体进度卡片（进度条 + 状态标签）
- 下方：按漫画名折叠的进度面板（`_GlassProgressPanel`）
  - 头部：漫画名 + 文件统计 + 该组总进度条 + `›` 折叠箭头
  - 展开：每个文件的迷你进度条（`_MiniBar`，4px 细条）
- 完成后自动调用 `organize_comics_into_folders(output_dir, {".pdf"})` 归类
- 完成态：进度条变绿 `#34c759`，失败态变红 `#ff3b30`

**转换流程**：
1. 创建临时目录
2. 解压压缩包（zip/rar/7z/cbz/cbr）
3. 递归查找所有图片（jpg/png/webp/bmp/gif/tiff）
4. natsort 自然排序
5. `img2pdf.convert()` 无损生成 PDF
6. 清理临时目录
7. 可选删除源压缩包

---

### 三、Tab2：Kindle 漫画转换（`kindle_tab.py`）

**Step 1 — 路径设置**
- 三张毛玻璃卡片：Kindle 缓存/输入文件夹 + 输出文件夹 + Calibre 安装路径
- Kindle 路径自动检测 `~/Documents/My Kindle Content`
- Calibre 路径自动检测 `C:\Program Files\Calibre2` 等常见位置

**Step 2 — 文件列表**
- 扫描 `My Kindle Content` 下匹配 `{ID}_PDOC` 模式的文件夹
- 读取对应的 `{ID}_PDOC/{ID}_PDOC.azw` 文件
- 调用 `ebook-meta.exe` 解析每个文件的真实标题（使用配置的 Calibre 路径）
- 列表列：原始ID、解析标题、大小、状态
- 按解析标题提取漫画名进行分组折叠
- "刷新元数据" 按钮可重新解析标题
- "输出格式" 下拉框：PDF/EPUB/MOBI/AZW3/CBZ
- 底部：删除源文件复选框 + 返回 + 开始转换

**Step 3 — 进度面板**
- 同 Tab1 的折叠进度面板
- 完成后按输出格式归类到文件夹

**转换流程**：
1. 使用配置的 `ebook-convert.exe` 路径调用 Calibre
2. 输出文件名使用解析后的标题（`_sanitize_filename` 过滤非法字符 `<>:"/\|?*`）
3. 若未解析到标题则回退使用原始 PDOC ID
4. 可选删除 Kindle 缓存中的源文件夹

### 四、漫画名自动识别（`comic_grouper.py`）

**核心函数** `extract_comic_name(filename_no_ext)` 通过正则匹配卷/话编号模式，提取纯净漫画名。

**识别模式（优先级从高到低）**：

| 模式类别 | 示例 | 提取结果 |
|---------|------|---------|
| 破折号分隔 | `海贼王 - 卷1`、`进击的巨人 – Vol.1` | `海贼王` |
| 英文卷标识 | `One Piece Vol.01`、`Naruto Ch.001`、`Bleach v01` | `One Piece` |
| 第X卷/话 | `海贼王 第01卷`、`龙珠 第1话`、`鬼灭 第1册` | `海贼王` |
| 卷/话/册/部在后 | `海贼王 卷1`、`银魂 话2`、`龙珠 册1`、`JOJO 部3` | `海贼王` |
| 卷/话/册/部在前 | `海贼王 01卷`、`银魂 02话`、`龙珠 03册` | `海贼王` |
| 括号编号 | `咒术回战 (01)`、`鬼灭之刃 [02]` | `咒术回战` |
| 尾部纯数字 | `银魂 01`、`鬼灭_v02`、`钢炼-03` | `银魂` |
| 井号编号 | `MyHero #001` | `MyHero` |
| No.编号 | `Bleach No. 001` | `Bleach` |
| Season/Part/Book/Volume | `Dr.Stone Season 1` | `Dr.Stone` |
| 完结标记 | `孤独的美食家 (完结)` | `孤独的美食家` |

**自动归类** `organize_comics_into_folders(directory, extensions)`：
- 扫描输出目录中指定扩展名的文件
- 按漫画名分组
- 组内 ≥2 个文件 → 创建 `漫画名/` 文件夹并移入
- 组内仅 1 个文件 → 保持在目录根

**尾部清理**：`_TRAILING_CLEAN = re.compile(r'[-–—_,.\s]+$')` 清理残留的分隔符。

### 五、多线程架构（`task_manager.py`）

**设计原则**：必须使用 `QThread`，严禁 `ThreadPoolExecutor`（会导致 PySide6 信号崩溃）。

**核心类**：
- `TaskItem`：dataclass，包含 task_id、name、status、progress、status_text、error_message、metadata
- `TaskSignals(QObject)`：三个信号
  - `progress_updated(str task_id, int percent, str text)`
  - `task_finished(str task_id, bool success, str message)`
  - `all_finished()`
- `_WorkerThread(QThread)`：包装单个转换任务
  - `run()` 中发射 `progress_updated` 和 `task_finished`
  - 异常捕获到 `task_finished(task_id, False, str(e))`
- `TaskManager(QObject)`：管理任务队列和线程池
  - `max_workers`：默认 `min(cpu_count, 4)`
  - `add_task()` / `remove_task()` / `clear_tasks()` / `cancel_all()`
  - `run(worker_fn)`：启动任务处理
  - `_start_next()`：从等待队列取下一个任务，创建 `_WorkerThread` 并启动
  - `_on_task_done_slot()`：连接 `task_finished` 信号，递减活跃计数，启动下一任务，判断全部完成

**信号流**：
1. Tab 在 `__init__` 中连接 `all_finished` → `_on_all_finished`
2. `_WorkerThread.run()` 发射 `progress_updated` 和 `task_finished`
3. `TaskManager._on_task_done_slot` 接收 `task_finished`，管理队列，发射 `all_finished`
4. Tab 的 `_on_progress` 和 `_on_task_finished` 更新进度 UI
5. Tab 的 `_on_all_finished` 显示完成按钮 + 调用 `organize_comics_into_folders()`

### 七、常见问题与修复记录

1. **点击开始转换崩溃**：`ThreadPoolExecutor` 的 Python 线程发射 Qt 信号导致 Windows 上崩溃 → 改用 `QThread`
2. **完成后崩溃**：`_CompletionMonitor` 的 QThread 中直接调 UI 方法 → 改用 `all_finished` 信号
3. **QPushButton 未定义**：`progress_widget.py` 改用 QPushButton 做箭头后漏导入 → 已补
4. **列表复选框叠在字段上**：表格列数没给复选框留专用列 → 第 0 列固定 42px 放复选框
5. **漫画名尾部残留 `-`**：`extract_comic_name` 析出 `海贼王 -` → 正则清理尾部标点
6. **`海贼王 - 卷1` 无法识别**：缺少破折号前缀模式 → 新增 `[-–—]` 前缀的匹配规则
7. **`海贼王 卷1` 无法识别**：只有 `\d+卷` 模式，没 `卷\d+` → 新增双向模式
8. **路径不记忆**：无持久化 → 新增 `QSettings` 存储
9. **输出文件名用原始ID**：未传 `output_name` → 传 `parsed_title` + 文件名净化
