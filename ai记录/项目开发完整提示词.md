## 项目概述

Comic Binder 是一个基于 Python + PySide6 的桌面 GUI 应用，用于将漫画压缩包和 Kindle 下载的漫画文件批量转换为 PDF/EPUB 等格式。支持自动识别漫画系列名、将同一漫画的不同卷/话归入文件夹、多线程并行处理、进度追踪。

---

## 技术栈

| 类别 | 技术 |
|------|------|
| 语言 | Python 3.10+ |
| GUI 框架 | PySide6 (Qt for Python) |
| 压缩包处理 | `zipfile`(内置)、`rarfile`、`py7zr`、`patool` |
| PDF 生成 | `img2pdf` (无损，保持图片质量) |
| 图片处理 | `Pillow` |
| Kindle 转换 | Calibre 的 `ebook-convert` 和 `ebook-meta` CLI 工具 |
| 自然排序 | `natsort` |
| 配置持久化 | `QSettings` |
| 多线程 | `QThread` (严禁使用 `ThreadPoolExecutor`) |

## 详细功能说明

### 一、全局设计

**UI 风格**：iOS 毛玻璃卡片风格
- 整体背景 `#f2f2f7`
- 卡片 `rgba(255,255,255,0.72)` 半透明白，`0.5px` 细边框，`16px` 连续圆角
- 主色调 `#007aff` iOS 蓝；绿色 `#34c759`；红色 `#ff3b30`
- 字体优先 SF Pro Display → 微软雅黑 → PingFang SC（精确选择器，禁用 `*` 通配符）

**路径持久化**：所有路径通过 `QSettings("ComicBinder", "ComicBinder")` 自动保存和恢复。

**悬浮提示**：自定义 `custom_tooltip.py`（`TipLabel` + 事件过滤器），白底黑字，`setWordWrap(True)` 多行展示，`setMaximumWidth(400)`，定位在组件正上方。

**列表统一规则**：
- `NoEditTriggers` + `ItemIsSelectable | ItemIsEnabled`（不含 `ItemIsEditable`）→ 纯展示
- `StrongFocus` → 支持 `Ctrl+C` 复制
- `cellEntered` + 自定义 tooltip → 文本超出列宽时悬浮显示
- 点击行不切换复选框（仅通过复选框本身操作）
- `setShowGrid(True)` → 始终显示表格线

---

### 二、AnimatedCheckBox（`animated_checkbox.py`）

全部复选框使用自定义组件，继承 QCheckBox，QPainter 自绘：

| 属性 | 值 |
|------|-----|
| 指示器尺寸 | 16×16px |
| 最小尺寸 | 20×20px |
| 圆角半径 | 5px |
| 未选中 | 1.5px 描边 `rgba(200,200,210,0.35)`，透明背景 |
| 选中渐变 | 135deg `#6366f1` → `#a855f7` → `#ec4899` |
| 选中发光 | 双层半透明紫光晕 |
| 选中勾号 | 白色 2.5px 圆角端点路径 ✓ |
| 脉冲动画 | QPropertyAnimation 380ms：scale(1→0.82→1.1→1) |
| 勾号绘入 | 独立 checkDraw 动画 350ms，延迟 80ms 启动 |
| Hover | 描边提亮 + 微弱光晕 |
| 按压 | scale(0.94) 触控反馈 |
| `hitButton` | 返回 `True`（点击文字也切换） |
| 尺寸策略 | `Expanding`，`sizeHint()` 按文本实际宽度计算 |

---

### 三、Tab1：压缩包转 PDF（`archive_tab.py`）

**模式**：`FileListWidget(grouped=False)` — 所有文件平铺展示，按漫画名字母序排序。

**列**：`文件名 | 漫画名称 | 大小 | 类型 | 状态`

**Step 1** — 文件夹设置（两张毛玻璃卡片）
**Step 2** — 文件列表（单面板，表头可见，工具栏：搜索/全选/取消全选/删除选中）
**Step 3** — 进度表（表格 + 总体进度卡）

**转换前预处理**：
1. 按漫画名分组预创建文件夹（≥2 同漫画建子文件夹）
2. 检测同名文件弹窗（覆盖全部/跳过同名/取消）

**完成后**：静默 `organize_comics_into_folders`，不弹窗。

---

### 四、Tab2：Kindle 漫画转换（`kindle_tab.py`）

**模式**：`FileListWidget(grouped=False)` — 平铺，按漫画名字母序排序。

**列**：`原始ID | 解析标题 | 大小 | 状态`

**扫描**：QThread 异步执行 `scan_kindle_files`（不阻塞 UI），按钮显示「扫描中...」

**Step 1** — 三张毛玻璃卡片（Kindle 缓存/输出/Calibre 路径）
**Step 2** — 文件列表 + 输出格式下拉 + 刷新元数据
**Step 3** — 进度表

**删除逻辑**：`delete_source=True` → `shutil.rmtree(folder_path)` 删除整个 PDOC 文件夹。

**ebook 调用**：`creationflags=CREATE_NO_WINDOW` 隐藏终端窗口。

---

### 五、漫画名自动识别（`comic_grouper.py`）

**`extract_comic_name(filename_no_ext)`** — 正则匹配卷/话编号模式，返回最短匹配（≥2 字符）。

**`organize_comics_into_folders(directory, extensions)`**：扫描目录 → 分组 → ≥2 创建文件夹移入 → 单文件原位。返回创建数。

---

### 六、多线程架构（`task_manager.py`）

**设计原则**：必须使用 `QThread`，严禁 `ThreadPoolExecutor`。

**完成检测**：`_done_count >= _total_count` 精确计数。

信号流：
```
_WorkerThread.run() → emit task_finished
  → TaskManager._on_task_done_slot: _done_count++
    → if _done_count >= _total_count: emit all_finished
      → Tab._on_all_finished（UI 更新 + 静默归类）
```

---

### 七、进度表（`progress_widget.py`）

表格列：`文件名 | 漫画名 | 状态 | 错误原因 | 进度`

- 排序：漫画名 A→Z → 状态优先（处理中→等待中→已完成→失败）→ 进度% 高→低
- 失败信息在「错误原因」列展示，不弹窗
- 300ms 防抖排序避免高频更新卡顿
- 进度条颜色：完成绿/失败红底黑字/处理中蓝/等待中灰

---

### 八、悬浮提示（`custom_tooltip.py`）

- 白底 `#ffffff`，黑字，圆角 8px，多行 `setWordWrap(True)`，最大宽 400px
- 仅文本被截断时显示（`fontMetrics.horizontalAdvance > colWidth`）
- 定位在触发元素正上方
