## 项目概述

Comic Binder 是一个基于 Python + PySide6 的桌面 GUI 应用，用于将漫画压缩包和 Kindle 下载的漫画文件批量转换为 PDF/EPUB 等格式。支持自动识别漫画系列名、将同一漫画的不同卷/话归入文件夹、多线程并行处理、进度追踪。

---

## 技术栈

| 类别 | 技术 |
|------|------|
| 语言 | Python 3.10+ |
| GUI 框架 | PySide6 (Qt for Python) |
| 压缩包处理 | `zipfile`(内置)、`rarfile`、`py7zr`、`patool` |
| PDF 生成 | `img2pdf` (无损，保持图片质量) |
| 图片处理 | `Pillow` |
| Kindle 转换 | Calibre 的 `ebook-convert` 和 `ebook-meta` CLI 工具 |
| 自然排序 | `natsort` |
| 配置持久化 | `QSettings` |
| 多线程 | `QThread` (严禁使用 `ThreadPoolExecutor`) |

## 详细功能说明

### 一、全局设计

**UI 风格**：iOS 毛玻璃卡片风格
- 整体背景 `#f2f2f7`
- 卡片 `rgba(255,255,255,0.72)` 半透明白，`0.5px` 细边框，`16px` 连续圆角
- 主色调 `#007aff` iOS 蓝；绿色 `#34c759`；红色 `#ff3b30`
- 字体优先 SF Pro Display → 微软雅黑 → PingFang SC（精确匹配选择器，不用 `*` 通配符，避免破坏 QToolTip 渲染）
- Tab 栏胶囊式切换，选中白底蓝字

**路径持久化**：所有路径通过 `QSettings("ComicBinder", "ComicBinder")` 自动保存和恢复。

**悬浮提示**：使用自定义 `custom_tooltip.py`（`TipLabel` + `HoverTip` 事件过滤器），白底 `#ffffff` + 深灰文字，定位在组件**正上方**。不使用系统 `QToolTip`，因为 Windows 上 Qt 无法可靠设置其样式。

---

### 二、AnimatedCheckBox（`animated_checkbox.py`）

全部复选框使用自定义组件，继承 QCheckBox，QPainter 自绘：

| 属性 | 值 |
|------|-----|
| 尺寸 | 22×22px 指示器，6px 圆角 |
| 未选中 | 1.5px 描边 `rgba(200,200,210,0.35)`，透明背景 |
| 选中渐变 | 135deg `#6366f1` → `#a855f7` → `#ec4899` |
| 选中发光 | 双层半透明紫光晕（9px + 12px 扩散） |
| 选中勾号 | 白色 2.5px 圆角端点路径 ✓ |
| 脉冲动画 | QPropertyAnimation 380ms：scale(1→0.82→1.1→1) |
| 勾号绘入 | 独立 checkDraw 动画 350ms，延迟 80ms 启动，裁剪区域渐进显现 |
| Hover | 描边提亮至 `rgba(168,85,247,0.4)` + 微弱光晕 |
| 按压 | scale(0.94) 触控反馈 |
| 键盘 | 继承 QCheckBox 原生 Tab/Space 支持 |
| 尺寸策略 | Expanding + 动态 text width 计算。`sizeHint()` 根据 `fontMetrics().horizontalAdvance()` 计算实际文本宽度 |

Property 命名注意：使用 `animProgress`（非 `_anim_progress`），内部用 `__anim_progress`（name mangling）避免递归。

### 三、Tab1：压缩包转 PDF（`archive_tab.py`）

**模式**：`FileListWidget(grouped=False)` — **不按漫画名折叠**，所有文件在单个"全部文件"面板中平铺展示。

**Step 1 — 文件夹设置**
- 两张毛玻璃卡片（`QFrame#glassCard`）：输入文件夹 + 输出文件夹
- 每张卡片：灰色小标签 + QLineEdit + "浏览" 按钮
- "扫描压缩包" 蓝色主按钮（`#primaryBtn`）

**Step 2 — 文件列表**
- 单一面板（不可折叠），表头显示 `☐ 文件名 | 大小 | 类型 | 状态`
- 工具栏：搜索 + 全选/取消全选/删除选中
- 单元格可选中复制 + 悬浮提示（custom_tooltip）
- 底部：`AnimatedCheckBox("转换完成后删除源压缩包")` + 返回 + 开始转换

**Step 3 — 进度面板**
- 总体进度卡片 + 按漫画名折叠的进度面板
- 完成后调用 `organize_comics_into_folders(output_dir, {".pdf"})`
- 弹窗告知归类结果（含诊断信息）

---

### 四、Tab2：Kindle 漫画转换（`kindle_tab.py`）

**模式**：`FileListWidget(grouped=True)` — **按漫画名折叠分组**。

**Step 1 — 路径设置**
- 三张毛玻璃卡片：Kindle 缓存/输入 + 输出 + Calibre 安装路径

**Step 2 — 文件列表**
- 列：`原始ID | 解析标题 | 大小 | 状态`
- 按解析标题提取漫画名进行分组折叠
- **滚动策略**：≤3 文件完整展示；4-6 文件表内滚动；>6 文件启用分页（每页 6 条，底部 `< 1/3 >` 翻页）
- 工具栏：展开全部/折叠全部 + 全选/取消全选/删除选中
- 底部复选框：`"转换后删除 Kindle 缓存源文件夹"`（14字）

**Step 3 — 进度面板**
- 同 Tab1，完成后按输出格式归类
- **删除逻辑**：`shutil.rmtree(folder_path)` 删除整个 PDOC 文件夹

**输出文件名**：优先使用 `parsed_title`（`_sanitize_filename` 过滤 `<>:"/\|?*`），若为空则回退 PDOC ID。

---

### 五、漫画名自动识别（`comic_grouper.py`）

**`extract_comic_name(filename_no_ext)`** — 正则匹配卷/话编号模式，返回最短匹配（≥2 字符）。

| 模式 | 示例 | 结果 |
|------|------|------|
| 破折号 + 卷/话/数字 | `海贼王 - 卷1`、`鬼灭 — 01` | `海贼王` |
| 英文卷 | `One Piece Vol.01`、`Naruto Ch.001` | `One Piece` |
| 第X卷/话/册/部 | `海贼王 第01卷` | `海贼王` |
| 卷/话/册/部 后置 | `海贼王 卷1`、`银魂 话2` | `海贼王` |
| 卷/话/册/部 前置 | `海贼王 01卷` | `海贼王` |
| 括号/方括号编号 | `咒术回战 (01)` | `咒术回战` |
| 尾部纯数字 | `银魂 01`、`鬼灭_v02` | `银魂` |
| #/No./Season/Part/Book/Volume | `MyHero #001` | `MyHero` |

**`organize_comics_into_folders(directory, extensions)`**：扫描目录 → 按漫画名分组 → ≥2 创建文件夹移入 → 单文件原位。返回创建数。

### 六、多线程架构（`task_manager.py`）

**设计原则**：必须使用 `QThread`，严禁 `ThreadPoolExecutor`。

**完成检测**：使用 `_done_count >= _total_count` 精确计数（而非 `_active_count` 间接推断），确保 `all_finished` 在所有 `task_finished` 信号处理完毕后发射。

```
_WorkerThread.run() → emit task_finished
  → TaskManager._on_task_done_slot: _done_count++
    → if _done_count >= _total_count: emit all_finished
      → Tab._on_all_finished（UI 更新 + 归类）
```

---

### 七、错误处理

所有失败通过 `QMessageBox.critical` 弹窗，包含：文件名 + 路径 + 错误原因。

---

### 八、悬浮提示（`custom_tooltip.py`）

不依赖系统 `QToolTip`（Windows 上 Qt 无法可靠设置样式），使用自定义浮层：
- `TipLabel`：独立无边框 QLabel，白底 `#ffffff`，深灰文字，自动消失 5s
- `HoverTip`：事件过滤器监听 Enter/Leave
- 表格单元格：通过 `cellEntered` 信号 + viewport `eventFilter` 实现

### 十一、已知问题与修复记录

1. **ThreadPoolExecutor 崩溃** → 改用 QThread
2. **完成后崩溃** → `_CompletionMonitor` 直接调 UI → 改用信号
3. **QPushButton 未定义** → `progress_widget.py` 补导入
4. **复选框叠字段** → 表格列数 +1，第 0 列 42px 放复选框
5. **漫画名尾部残留 `-`** → `_TRAILING_CLEAN` 正则清理
6. **`海贼王 - 卷1` 无法识别** → 新增 `[-–—]` 前缀模式
7. **`海贼王 卷1` 无法识别** → 新增 `卷\d+` 双向模式
8. **路径不记忆** → QSettings 持久化
9. **输出文件名用 PDOC ID** → 传 `parsed_title` + `_sanitize_filename`
10. **复选框 Property 递归** → 内部变量 `__anim_progress`（name mangling）
11. **Tab2 复选框文字过长** → 缩为 14 字 + `Expanding` size policy
12. **缺少表头** → `horizontalHeader().setVisible(True)` + 32px 灰色表头
13. **错误无弹窗** → `_on_task_finished` 添加 `QMessageBox.critical`
14. **悬浮提示全黑** → `*` 通配符 CSS 选择器破坏 Windows QToolTip → 改用精确选择器 + 自定义 `custom_tooltip.py` 浮层
15. **分组不触发** → `_on_task_done_slot` 守卫条件 `not [] and 0 <= 0` 在最终任务时提前 return → 改用 `_done_count >= _total_count` 精确判断
16. **Tab1 不应折叠** → `FileListWidget(grouped=False)` 平铺模式
17. **Tab2 长列表无分页** → 表内滚动 + 每页 6 条分页控件
