## 项目概述

Comic Binder 是一个基于 Python + PySide6 的桌面 GUI 应用，用于将漫画压缩包和 Kindle 下载的漫画文件批量转换为 PDF/EPUB 等格式。支持自动识别漫画系列名、将同一漫画的不同卷/话归入文件夹、多线程并行处理、进度追踪。

---

## 技术栈

| 类别 | 技术 |
|------|------|
| 语言 | Python 3.10+ |
| GUI 框架 | PySide6 (Qt for Python) |
| 压缩包处理 | `zipfile`(内置)、`rarfile`、`py7zr`、`patool` |
| PDF 生成 | `img2pdf` (无损，保持图片质量) |
| 图片处理 | `Pillow` |
| Kindle 转换 | Calibre 的 `ebook-convert` 和 `ebook-meta` CLI 工具 |
| 自然排序 | `natsort` |
| 配置持久化 | `QSettings` |
| 多线程 | `QThread` (严禁使用 `ThreadPoolExecutor`) |

## 详细功能说明

### 一、全局设计

**UI 风格**：iOS 毛玻璃卡片风格
- 整体背景 `#f2f2f7`
- 卡片 `rgba(255,255,255,0.72)` 半透明白，`0.5px` 细边框，`16px` 连续圆角
- 主色调 `#007aff` iOS 蓝；绿色 `#34c759`；红色 `#ff3b30`
- 字体优先 SF Pro Display → 微软雅黑 → PingFang SC
- Tab 栏胶囊式切换，选中白底蓝字

**折叠面板**（`_GlassPanel` / `_GlassProgressPanel`）：
- 头部 50px，左侧粗体标题 + 右侧 `›`/`⌄` 箭头（QPushButton，28×28px）
- 点击头部或箭头切换展开/折叠，箭头旋转并变色
- 展开内容白色底，16px 内边距

**路径持久化**：所有输入/输出/Calibre 路径通过 `QSettings("ComicBinder", "ComicBinder")` 自动保存和恢复。

### 二、AnimatedCheckBox（`animated_checkbox.py`）

全部复选框使用自定义 `AnimatedCheckBox` 组件，继承 QCheckBox，完全自绘：

| 属性 | 值 |
|------|-----|
| 尺寸 | 22×22px 指示器，6px 圆角 |
| 未选中 | 1.5px 描边 `rgba(200,200,210,0.35)`，透明背景 |
| 选中渐变 | 135deg `#6366f1` → `#a855f7` → `#ec4899` |
| 选中发光 | 双层半透明紫光晕（9px + 12px 扩散） |
| 选中勾号 | 白色 2.5px 圆角端点路径 ✓ |
| 脉冲动画 | QPropertyAnimation 380ms：scale(1→0.82→1.1→1) |
| 勾号绘入 | 独立 checkDraw 动画 350ms，延迟 80ms 启动 |
| Hover | 描边提亮至 `rgba(168,85,247,0.4)` + 微弱光晕 |

| 尺寸策略 | `Expanding` + 动态 text width 计算 |

替换位置：Tab1/Tab2 底部复选框、文件列表组复选框、行内复选框。

### 三、Tab1：压缩包转 PDF（`archive_tab.py`）

**Step 1 — 文件夹设置**
- 两张毛玻璃卡片（`QFrame#glassCard`）：输入文件夹 + 输出文件夹
- 每张卡片：灰色小标签 + QLineEdit + "浏览" 按钮
- "扫描压缩包" 蓝色主按钮（`#primaryBtn`）
- 路径恢复：`get_last_path("archive/input_dir")` / `get_last_path("archive/output_dir")`

**Step 2 — 文件列表**
- 使用 `FileListWidget`，列：`["文件名", "大小", "类型", "状态"]`
- 按漫画名自动分组折叠（内部调用 `extract_comic_name`）
- 每个漫画组一个 `_GlassPanel`：
  - 头部：AnimatedCheckBox + 漫画名（粗体 15px）+ 文件统计 + `›` 箭头
  - 展开：QTableWidget（表头可见，32px 高灰色小字）
  - 列 0 = 复选框（42px 固定），列 1..N = 数据列（stretch）
  - 行高 42px，交替行色，选中行淡紫底色
  - 单元格可选中复制（`ItemIsSelectable | ItemIsEnabled`）
- 工具栏：搜索 + 展开全部/折叠全部/全选/取消全选/删除选中
- 搜索匹配漫画名 + 所有字段值，跨组过滤
- 底部：`AnimatedCheckBox("转换完成后删除源压缩包")` + 返回 + 开始转换

**Step 3 — 进度面板**
- 总体进度卡片 + 按漫画名折叠的 `_GlassProgressPanel`
- 头部：漫画名 + 文件统计 + 组总进度条（120px）+ `›` 箭头
- 展开：`_MiniBar`（4px 细进度条，完成绿/失败红/进行中蓝）
- `_on_all_finished` 中调用 `organize_comics_into_folders(output_dir, {".pdf"})`
- 完成后弹窗告知归类结果

**转换流程**：
1. 创建临时目录 → 解压 → 递归找图片 → natsort 排序 → img2pdf 生成 PDF → 清理临时目录 → 可选 `os.remove(archive_path)`

### 四、Tab2：Kindle 漫画转换（`kindle_tab.py`）

**Step 1 — 路径设置**
- 三张毛玻璃卡片：Kindle 缓存/输入 + 输出 + Calibre 安装路径
- Kindle 路径自动检测 `~/Documents/My Kindle Content`
- Calibre 路径自动检测常见位置 + 手动浏览

**Step 2 — 文件列表**
- 使用 `FileListWidget`，列：`["原始ID", "解析标题", "大小", "状态"]`
- 扫描 `My Kindle Content/{ID}_PDOC/` 模式文件夹
- 读取对应 `{ID}_PDOC.azw` 文件
- 调用 Calibre 的 `ebook-meta.exe` 解析真实标题
- 按解析标题提取漫画名进行分组折叠
- "刷新元数据" 按钮 + "输出格式" 下拉框（PDF/EPUB/MOBI/AZW3/CBZ）
- 底部复选框文案：`"转换后删除 Kindle 缓存源文件夹"`（14字，已缩至可完整显示）

**Step 3 — 进度面板**
- 同 Tab1 折叠面板，完成后调用 `organize_comics_into_folders(output_dir, {ext})`
- **删除逻辑**：`delete_source=True` + `folder_path` → `shutil.rmtree(folder_path)` 删除 `My Kindle Content/{ID}_PDOC/` 整个文件夹

**转换流程**：
1. `ebook-convert.exe azw_path output_path`（subprocess，encoding="utf-8"）
2. 输出文件名优先用 `parsed_title`（`_sanitize_filename` 过滤 `<>:"/\|?*`）
3. 解析 stdout 百分比作为进度
4. 可选删除 PDOC 源文件夹

### 五、漫画名自动识别（`comic_grouper.py`）

**核心函数** `extract_comic_name(filename_no_ext)` 正则匹配卷/话编号模式，返回纯净漫画名。选择最短匹配结果（≥2 字符）。

**识别模式**：

| 模式 | 示例 | 结果 |
|------|------|------|
| 破折号 + 卷/话 | `海贼王 - 卷1`、`进击 – Vol.1` | `海贼王` |
| 破折号 + 纯数字 | `鬼灭 — 01` | `鬼灭` |
| 英文卷 | `One Piece Vol.01`、`Naruto Ch.001`、`Bleach v01` | `One Piece` |
| 第X卷/话/册/部 | `海贼王 第01卷`、`龙珠 第1话` | `海贼王` |
| 卷/话/册/部 后置 | `海贼王 卷1`、`银魂 话2`、`龙珠 册1` | `海贼王` |
| 卷/话/册/部 前置 | `海贼王 01卷`、`银魂 02话` | `海贼王` |
| 括号/方括号编号 | `咒术回战 (01)`、`鬼灭 [02]` | `咒术回战` |
| 尾部纯数字 | `银魂 01`、`鬼灭_v02`、`钢炼-03` | `银魂` |
| #编号 | `MyHero #001` | `MyHero` |
| No.编号 | `Bleach No. 001` | `Bleach` |
| Season/Part/Book/Volume | `Dr.Stone Season 1` | `Dr.Stone` |
| 完结标记 | `孤独的美食家 (完结)` | `孤独的美食家` |

**尾部清理**：`_TRAILING_CLEAN = re.compile(r'[-–—_,.\s]+$')` 清除残留分隔符。

**`organize_comics_into_folders(directory, extensions)`**：
- 扫描目录中指定扩展名文件 → 按漫画名分组 → ≥2 文件创建文件夹并移入 → 单文件保持原位
- 返回创建的文件夹数量

### 六、多线程架构（`task_manager.py`）

**设计原则**：必须使用 `QThread`，严禁 `ThreadPoolExecutor`（Python 线程 emit Qt 信号在 Windows 上崩溃）。

**核心类**：
- `TaskItem`（dataclass）：task_id, name, status, progress, status_text, error_message, metadata
- `TaskSignals(QObject)`：`progress_updated(str, int, str)`, `task_finished(str, bool, str)`, `all_finished()`
- `_WorkerThread(QThread)`：`run()` 中执行 `worker_fn(task, progress_cb)`，捕获异常 → `task_finished(False, str(e))`
- `TaskManager(QObject)`：
  - `max_workers = min(cpu_count, 4)`
  - `add_task()` / `clear_tasks()` / `cancel_all()`
  - `run(worker_fn)`：启动，每次取 `max_workers` 个 pending 任务
  - `_start_next()`：从 `_pending_tasks` 队列 pop → 创建 `_WorkerThread` → `start()`
  - `_on_task_done_slot`（连接 `task_finished`）：递减 `_active_count`，调 `_start_next()`，判断 `all_finished`

**信号流**：
```
_WorkerThread.run() → emit task_finished
  → TaskManager._on_task_done_slot（管理队列）
    → emit all_finished
      → Tab._on_all_finished（UI 更新 + 归类）
```

### 七、错误处理

所有转换失败通过 `QMessageBox.critical` 弹窗展示，包含：
- 文件名（task.name）
- 完整路径（task_id / azw_path）
- 错误原因（异常消息）

覆盖层级：
- `_start_conversion` try/except → 弹窗
- `_WorkerThread.run()` 异常捕获 → `task_finished(False, msg)` → Tab `_on_task_finished` 弹窗
- `archive_converter.py` / `kindle_converter.py` 抛异常时包含文件路径上下文

### 九、打包为 Windows 独立 EXE

使用 PyInstaller 将项目打包为无需 Python 环境的独立可执行程序。

**安装 PyInstaller**：
```bash
pip install pyinstaller
```

**打包命令**（在项目根目录执行）：
```bash
pyinstaller --name "ComicBinder" --noconsole --onedir ^
    --hidden-import src ^
    --hidden-import src.core ^
    --hidden-import src.core.archive_scanner ^
    --hidden-import src.core.archive_converter ^
    --hidden-import src.core.kindle_scanner ^
    --hidden-import src.core.kindle_converter ^
    --hidden-import src.core.task_manager ^
    --hidden-import src.ui ^
    --hidden-import src.ui.main_window ^
    --hidden-import src.ui.archive_tab ^
    --hidden-import src.ui.kindle_tab ^
    --hidden-import src.ui.widgets ^
    --hidden-import src.ui.widgets.file_list_widget ^
    --hidden-import src.ui.widgets.progress_widget ^
    --hidden-import src.ui.widgets.animated_checkbox ^
    --hidden-import src.utils ^
    --hidden-import src.utils.helpers ^
    --hidden-import src.utils.settings ^
    --hidden-import src.utils.comic_grouper ^
    --hidden-import rarfile ^
    --hidden-import py7zr ^
    --hidden-import natsort ^
    --hidden-import img2pdf ^
    --hidden-import patoolib ^
    --add-data "requirements.txt;." ^
    main.py
```

**产物位置**：`dist/ComicBinder/`

```
dist/ComicBinder/
├── ComicBinder.exe        ← 双击启动
└── _internal/             ← 运行时依赖（~181MB）
```

**分发方式**：将整个 `ComicBinder` 文件夹复制到目标 Windows 电脑，无需安装 Python 或任何依赖。

**注意事项**：
- `--onedir` 模式比 `--onefile` 启动更快、更稳定
- Tab2 仍需目标电脑安装 Calibre（`ebook-convert.exe` / `ebook-meta.exe` 为外部工具，未打包）
- Tab1 完全独立，无需任何外部依赖
- 可用 `--icon=icon.ico` 参数指定程序图标

### 十、已知问题与修复记录

6. **`海贼王 - 卷1` 无法识别** → 新增 `[-–—]` 前缀模式
7. **`海贼王 卷1` 无法识别** → 新增 `卷\d+` 双向模式
8. **路径不记忆** → `QSettings` 持久化
9. **输出文件名用 PDOC ID** → 传 `parsed_title` + `_sanitize_filename`
10. **复选框 Property 递归** → 内部变量改 `__anim_progress`（name mangling）
